# Distribuciones Continuas Interactivas

Este repositorio contiene un visualizador interactivo de distribuciones de probabilidad **continuas**, desarrollado como herramienta educativa para apoyar la enseñanza del curso **II-0306 Probabilidad y Estadística** de la Escuela de Ingeniería Industrial de la Universidad de Costa Rica.

## 📊 Distribuciones incluidas

- **Normal** (`μ`, `σ`)
- **Exponencial** (`λ`)
- **Gamma** (`r`, `λ`) — *forma y escala*
- **Weibull** (`β`, `δ`) — *forma y escala*
- **Lognormal** (`θ`, `ω`) — *media log y desviación logarítmica*
- **Beta** (`α`, `β`)

## 🛠️ Tecnologías usadas

- [Plotly.js](https://plotly.com/javascript/) para la visualización de los gráficos
- [jStat.js](https://jstat.github.io/) para el cálculo de funciones de densidad
- HTML + JavaScript puro
- [R](https://www.r-project.org/) para la generación del archivo HTML

## 📁 Estructura del repositorio

- `distribuciones_continuas_interactivas.html`: archivo HTML interactivo principal
- `generador.R`: script en R que genera el archivo HTML
- `README.md`: este archivo
